# source/

A curated, read-only copy of parts of the private Agentic Studio repository. It is here
to be read, not run:

- Paths mirror the private repository (`.github/`, `src/`, `tests/`, `macos/`, `schemas/`).
  The workflow sits under `source/.github/`, so GitHub does not run it here.
- The two freelance marketplaces are renamed `MarketA` / `market_a` and `MarketB` /
  `market_b`, and the community forum `Board` / `board`, with their domains replaced by
  `.example` hosts. Nothing else is edited; comments, decisions and dates are the originals.
- Not included: the adapters for those three platforms and their tests, the LLM triage and
  reply prompts, and the recorded test fixtures. Imports of them do not resolve here.

See the repository README for what each part shows.
